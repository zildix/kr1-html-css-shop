## Описание проекта

Многостраничный интернет-магазин современной электроники и гейминга (**ShopProject**). Проект реализован на чистом семантическом HTML5 и модульном CSS3 с применением методологии БЭМ, сеток CSS Grid и Flexbox, адаптивных CSS-переменных, а также нативного модального окна `<dialog>` с клиентской валидацией формы заявки.

Проект выполнен в соответствии с методическими требованиями к Контрольной работе №1 без использования сторонних CSS/JS-библиотек и фреймворков.

## Технические решения и реализация требований ТЗ

### 1. Семантическая HTML-разметка

* Строго соблюдена иерархия документов: единый тег `<main>` на страницу, логические разделы разбиты через `<section>`, самостоятельные сущности товаров и преимуществ оформлены тегами `<article>`.
* Использованы теги `<header>`, `<nav>`, `<aside>`, `<footer>`.
* Таблицы характеристик оформлены по стандартам доступности: с тегами `<caption>`, `<thead>`, `<tbody>`, `<th>` и `<td>`.

### 2. Навигация и якорные переходы

* Сквозное главное меню присутствует на всех страницах с визуальным выделением активного пункта модификатором `site-nav__link--active`.
* Настроены многостраничные якорные ссылки на ключевые секции главной страницы:
* `index.html#advantages` — блок преимуществ;
* `index.html#popular` — блок популярных товаров;
* `index.html#feedback` / `#contacts` — форма обратной связи и подвал.
* Для активных якорей настроена подсветка через CSS-псевдокласс `:target`.
* Для глубоких страниц реализованы «хлебные крошки» (`breadcrumbs`).

### 3. Формы и модальное окно

* Реализованы два независимых сценария заявки:
1. Нативное модальное окно `<dialog class="order-dialog">`, вызываемое кнопками «Заказать» с автоподстановкой имени товара через `dataset.product`.
2. Выделенная страница `order.html` с ручным выбором позиции из каталога.


* Все элементы формы имеют строгую связку `<label for="...">` с `id` инпута.
* Обязательные поля помечены атрибутом `required`, настроена валидация адреса электронной почты (`type="email"`), телефонного номера (`type="tel"`).
* Реализована стилизация ошибок валидации через селектор `[aria-invalid="true"]`.

### 4. CSS-архитектура и методология БЭМ

* В `:root` вынесены ключевые дизайн-токены: цветовая палитра, системные отступы (`--space-*`), радиусы скругления (`--radius-*`) и максимальная ширина контейнера.
* Стилизованы интерактивные состояния: `:hover`, `:focus-visible` (доступность при навигации с клавиатуры), `:disabled`.
* Классы сформированы по методологии БЭМ без использования селекторов по `id` или тегам внутри компонентов:
* Блоки: `site-header`, `site-nav`, `product-card`, `catalog-layout`, `order-form`, `order-dialog`.
* Элементы: `product-card__title`, `product-card__price`, `site-nav__link`.
* Модификаторы: `site-nav__link--active`, `button--primary`, `product-card--discount`.

### 5. Позиционирование элементов

* `position: sticky` — закрепление шапки сайта (`site-header`) при вертикальной прокрутке страницы.
* `position: relative` + `position: absolute` — позиционирование акцентных бейджей статуса («Хит», «Скидка») поверх изображения внутри контейнера карточки `product-card`.
* `z-index` — управление слоями шапки (`z-index: 100`) и модального диалога над общим контентом.

### 6. Сетки Flexbox и CSS Grid

* **Flexbox:**
* Горизонтальное выравнивание и распределение ссылок в шапке (`site-nav__list`);
* Внутренняя раскладка карточки товара (`product-card`) с прижатием кнопки заказа к нижней границе через `margin-top: auto`;
* Группировка кнопок действий в формах (`order-form__actions`).


* **CSS Grid:**
* Макет каталога `catalog-layout` с именованными областями `grid-template-areas: "filters products"` (боковая панель 260px и резиновая контентная область);
* Адаптивная витрина товаров `products-grid` (`repeat(3, 1fr)`);
* Двухколоночный макет страницы детального просмотра товара `product-page__inner` (медиа + блок покупки);
* Сетка преимуществ `advantages-grid` (`repeat(4, 1fr)`).

## Используемые технологии

* **HTML5:** Семантическая разметка, микроразметка, нативный тег диалога `<dialog>`.
* **CSS3:** Custom Properties (переменные), Flexbox, CSS Grid Layout, CSS Transitions, псевдоклассы состояний.
* **JavaScript (ES6):** Минимальный нативный скрипт для управления модальным окном (`showModal`/`close`), связывания названий товаров через `data-product` и перехвата отправки формы.
* **Git & GitHub Pages:** Контроль версий, ветвление, хостинг статических страниц.
